
Proyecto de Flutter para Adultos Mayores

Descripción del Proyecto

Esta aplicación Flutter está diseñada específicamente para mejorar la experiencia digital de adultos mayores, con interfaces accesibles, tipografía legible y funcionalidades adaptadas a sus necesidades.

Características Principales

Interfaz de usuario accesible: Botones grandes, contraste adecuado y navegación intuitiva

Tipografía ampliable: Texto legible con opciones de aumento

Funcionalidades prácticas: Recordatorios, contactos de emergencia, noticias relevantes

Diseño inclusivo: Consideraciones especiales para capacidades visuales y motoras
